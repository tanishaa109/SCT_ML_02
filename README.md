# SCT_ML_02 - Customer Segmentation using K-Means Clustering

## Objective

This project uses K-Means Clustering to segment retail store customers based on their Annual Income and Spending Score.

## Dataset

Mall Customers Dataset from Kaggle

## Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-Learn

## Project Workflow

1. Load customer dataset
2. Select Annual Income and Spending Score
3. Apply Elbow Method
4. Determine optimal number of clusters
5. Train K-Means model
6. Visualize customer segments
